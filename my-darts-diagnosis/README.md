# マイダーツ診断

12の質問に答えるだけで、自分に合うダーツバレルのスペックと、実際に買える製品候補が分かる無料Webアプリです。登録不要、iPhone / Android / PC のブラウザでそのまま使えます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・デザイン・診断ロジック（これ1つでアプリ本体） |
| `products.js` | 商品データ。**商品の差し替え・更新はこのファイルだけ**を編集します |
| `CLAUDE_CODE_PROMPT.md` | 制作仕様書（設計の記録） |

## ローカルで開く

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

## GitHub Pages で公開する手順

1. GitHub に新規リポジトリ（例：`my-darts-diagnosis`）を作成する
2. `index.html` と `products.js`（とこの README）をリポジトリにアップロードする
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、ブランチを `main` / `(root)` に設定する
4. 数分後に `https://<ユーザー名>.github.io/my-darts-diagnosis/` で公開される
5. 公開URLが決まったら、`index.html` 内の定数 `APP_URL` をそのURLに合わせる（Xシェア文に入ります）

## 商品データの更新方法（products.js）

- 商品を1件追加・変更するには、`PRODUCTS` 配列のオブジェクトを編集します
- 項目の意味は products.js 先頭のコメントにあります。ページに明記がない項目は `null` のままにしてください（診断では中立扱いになります）
- 売り切れたら `inStock: false` にすると結果に出なくなります
- 価格や在庫を確認したら `checkedAt` を確認日（YYYY-MM-DD）に更新してください

### ⚠ 公開前チェックリスト（必須）

価格・在庫は変動します。初期データは 2026-11-14 時点の確認記録です。**本公開の前に必ず**：

- [] 全商品の価格（税込）を販売ページで再確認し、`price` と `checkedAt` を更新する
- [] 全商品の在庫を確認し、売り切れは `inStock: false` にする
- [] 全商品の `url` が正しい販売ページに飛ぶか確認する（`url: ""` の商品はリンクが出ません）
- [] `price: null` の商品（CHARIS G5、BIONIC3、COSMO野毛、Cameron v2）は価格を確認して入力するか、商品自体を外す
- [] SANTANA と OGRE3 V4 GOLD は売り切れ確認済みのため `inStock: false` です。在庫が復活した場合のみ true に戻す

## 診断ロジックの概要

- 回答から推奨スペック（形／重さ／全長／最大径／重心／カット／タングステン率）を決定
- 「おまかせ」の項目は、グリップ位置・投げ方・プレースタイル・経験から補完（ルールは index.html 内のコメント参照）
- 商品マッチングは適合度スコア制：形の一致を最重視し、重さ・長さ・太さの差、重心、カット、予算で減点。売り切れ品は除外
